# بوابة مصاعد الفلك

- `index.html` — البوابة: الدخول بنفس حسابات نظام العروض (اسم المستخدم وكلمة المرور)، وبعدها روابط البرامج.
- `offers/` — عروض أسعار مصاعد الفلك (اللي مش داخل بيرجع للبوابة).
- `app.html?n=report` و `app.html?n=search` — التقارير والبحث عن حالة المصعد. البرنامجين متخزنين على سيرفر البوابة (Apps Script: app_report و app_search) ومش موجودين هنا، وما بيتبعتوش غير لحد داخل بحسابه.

البيانات والأسعار مش هنا، هي على Google Apps Script وشيت الشركة.
